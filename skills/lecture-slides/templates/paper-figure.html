② Residual Connection · ResNet

잔차 연결: 기울기가 두 경로로 전달된다

일반 신경망

층마다 f′(x)가 곱해져, 깊어질수록 기울기가 작아질 수 있음

잔차 연결

직접 경로로 출력 기울기가 그대로 더해져, f′(x)가 0에 가까워도 기울기가 전달됨

ResNet (2015)

잔차 연결이 핵심 아이디어. 이미지넷 대회 우승

출처: Kaiming He et al. (2015), Deep Residual Learning for Image Recognition · arxiv.org/abs/1512.03385

다음은 잔차 연결을 살펴보겠습니다. 잔차 연결을 왜 또 설명하지 하고 생각하실 수도 있지만, 그만큼 헷갈리고 중요해서 다시 설명드립니다. 기울기가 점점 작아져서 앞쪽 층의 파라미터가 거의 갱신되지 않고, 층을 깊게 쌓을수록 오히려 학습이 안 되는 상황을 기울기 소실 문제라고 했었죠. 이 문제를 해결한 것이 바로 레즈넷입니다. 레즈넷은 잔차 연결을 핵심 아이디어로 삼은 모델로, 2015년 이미지넷 대회에서 우승하면서 널리 알려졌습니다. 먼저 일반적인 신경망의 역전파 과정을 살펴보겠습니다. 순전파에서는 입력 x가 함수 f를 통과해 출력 y가 됩니다. 역전파에서는 출력 쪽에서 전달받은 기울기를 입력 쪽으로 전달합니다. 이때 입력 기울기는 출력 기울기에 현재 연산의 미분값을 곱해서 계산합니다. 다음으로 잔차 연결을 살펴보겠습니다. 잔차 연결은 함수의 출력에 입력을 직접 더하는 구조라서, 순전파는 x 더하기 f(x)가 됩니다. 이 구조에서는 역전파할 때 기울기가 두 경로로 전달됩니다. 첫 번째는 함수 f를 통과하는 변환 경로입니다. 이 경로에서는 출력 기울기에 함수의 미분값을 곱합니다. 두 번째는 입력을 직접 전달하는 경로입니다. x를 x로 미분하면 1이기 때문에, 이 경로에서는 출력 기울기가 그대로 입력으로 전달됩니다. 마지막으로 두 경로에서 계산된 기울기를 더합니다. 따라서 입력 기울기는 출력 기울기 곱하기 f 프라임 x 더하기 출력 기울기가 됩니다. 이처럼 잔차 연결은 기존 변환 경로에 직접 전달 경로를 추가합니다. 이 직접 경로로 기울기가 그대로 전달될 수 있기 때문에, 깊은 신경망에서도 기울기가 잘 전달됩니다. 이것이 잔차 연결이 깊은 신경망의 학습을 안정적으로 만드는 중요한 이유입니다.
