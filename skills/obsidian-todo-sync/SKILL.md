# Obsidian TODO 동기화 스킬

> 이 스킬은 뼈대입니다. 실제 볼트 경로와 규칙을 채워 넣은 뒤 사용하세요.

## 준비

- 볼트 경로: `<VAULT_PATH>` (사용자에게 확인)
- 수집 대상: `**/*.md`
- 제외 경로: `.obsidian/`, `templates/`, `archive/`

## 작업 절차

### 1단계: 할 일 수집

볼트 전체에서 체크박스 항목을 찾습니다.

- 미완료: `- [ ] `
- 완료: `- [x] `

각 항목에 대해 다음을 기록합니다.

- 원문 텍스트
- 소스 파일 경로와 줄 번호
- 태그(`#tag`), 날짜(`📅 YYYY-MM-DD`), 우선순위 표기가 있으면 함께 추출

### 2단계: 정리

기본 정렬 순서는 `마감일 → 우선순위 → 파일명` 입니다.
사용자가 다른 기준을 말하면 그것을 따릅니다.

### 3단계: 출력

볼트 루트에 `TODO.md` 를 생성하거나 갱신합니다.

    # TODO (자동 생성: YYYY-MM-DD)

    ## 기한 지남
    - [ ] 항목 텍스트 — [[소스파일]] (📅 2026-09-01)

    ## 이번 주
    - [ ] ...

    ## 기한 없음
    - [ ] ...

각 항목은 `[[위키링크]]`로 원본 노트를 가리켜 Obsidian 안에서 바로 이동할 수 있게 합니다.

## 주의

- **원본 노트를 수정하지 않습니다.** 기본 동작은 읽기 전용 수집입니다.
- 원본의 체크 상태까지 바꾸는 양방향 동기화는 사용자가 명시적으로 요청할 때만 수행하고,
  수행 전에 변경될 파일 목록을 먼저 보여 준 뒤 확인을 받습니다.
